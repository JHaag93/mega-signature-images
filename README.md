# Email signature images

Pictures used in Justin Haag's Mega Payments email signature, served by GitHub Pages so email programs can load them.

- `mega-logo-tile.png`: Mega logo on a white rounded tile (234 × 90, shown at 78 × 30), readable in light and dark mode.
- `kind-regards-tile.png`: "Kind regards," sign-off with rounded corners (238 × 123, shown at 110 × 57).

Don't rename or delete these files: every email already sent links to them.
